# 2D Drag Racing Game

A browser-based 2D drag racing game built with pure HTML, CSS and JavaScript.

## Features

- Two playable vehicles
- Independent vehicle physics
- Realistic acceleration and braking
- Automatic transmission system
- Vehicle-specific gear ratios
- Kickdown transmission logic
- Forward and reverse driving
- Camera switching system
- Infinite scrolling road
- Distance indicator between vehicles
- Side-view racing experience
- PNG-based vehicle models
- Lightweight and dependency-free

## Controls

### BMW i7
- W → Throttle
- S → Brake / Reverse

### Maybach
- A → Throttle
- D → Brake / Reverse

### Camera
- 1 → Focus BMW i7
- 2 → Focus Maybach

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Project Goal

This project aims to simulate a simple but engaging drag-racing experience with realistic vehicle behavior, automatic gear shifting, kickdown mechanics, momentum-based acceleration and independent camera tracking, all without using external libraries or game engines.
